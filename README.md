# 我的世界服务器购买：先按人数和模组量算配置，再搞清楚面板版、NAT 和计费模式

买 MC 服务器最常踩的坑，不是买贵了，而是买错方向。有人一上来挑最贵的 CPU，结果 6 个人玩纯净服；也有人图便宜买了 2 核 4G，转头开了 200 个模组的整合包，TPS 掉到个位数。服务器这东西，配置单看起来都是一个样，差别全在你会怎么用。

这篇不推销配置，讲清楚买之前该算什么、雨云（RainYun）这条产品线怎么选、价格和优惠到底长什么样，以及买完之后从哪一步开始动手。

## 买之前先算三件事

**玩家人数上限**。不是"现在几个人"，而是你预计高峰在线几个人。朋友服 5～10 人，社区服 20 人以上，性质完全不一样。

**服务端类型**。纯净服、插件服（Paper/Purpur）、模组服（Forge/Fabric）、基岩版，对硬件的要求差得很远。官方给出的参考基准是：纯净服和基岩服视距 6，模组服按 50 个 mod、视距 5 估算，Fabric 按 15 个 mod、视距 5 估算。同一台机器，纯净服能带 12 人，换成 200+ mod 的整合包就只能撑 1 个人。

**游戏版本**。1.18+ 的性能消耗大约是 1.16+ 的两倍、1.12.2 的三倍。低版本能跑得动的机器，升到高版本可能就不够了。

这三件事想清楚，配置其实就出来了。

## MC 服务器为什么该盯着 CPU 单核跑分

Minecraft 的主线程逻辑基本是单线程跑的，所以决定"卡不卡"的是单核性能，不是核心数量。一台 8 核低频机器跑 MC，往往不如 4 核高频。

雨云游戏云的产品页直接按 CPU-Z 单核跑分给机型划了档，机型覆盖从 E5 2666v3、Gold 6146 这类性价比型号，到 Ryzen 5900X、Ryzen 7950X、Ryzen 9950X 和 i9 14900K 这类高主频芯片。官方说法是把 14900K 系列做成纯大核（屏蔽小核），避免虚拟机被调度到小核上掉性能。

对应的判断也简单：

- **低版本纯净生存服**：低频型号够用，省下的钱可以多买内存
- **中高版本插件服**：优先选单核跑分中上、价格温和的型号
- **高版本模组服 / 整合包**：只考虑高主频型号，别在 CPU 上省钱

## 面板版还是整台 VPS

雨云在游戏云这条线下面给了两种买法，官方产品页把区别写得很直白。

| 对比项 | 雨云面板 / MCSM 面板 | 游戏云 VPS |
| --- | --- | --- |
| 你拿到的东西 | 预装好环境的面板，一键开服 | 完整的 Windows / Linux 服务器，自己装服务端或面板 |
| 运行方式 | 在 Docker 中运行，系统本身不占多少资源 | 系统层自由，可多开服务端、装别的程序 |
| 弹性 | 支持 CPU 升降级、可切换机型 | 支持随时升配降配、可选动态计费 |
| 适合的人 | 想尽快开服、只跑一个服务端 | 愿意自己折腾、要长期运营或跑多个服务 |

雨云面板是自研的，跑在 K8s 集群上，支持一键开服、可视化管理、备份和 MySQL，机型可以在 i9 14900KS 和 Platinum 8259CL 之间切换。MCSM 面板同样是全程网页操作，支持可视化和 SFTP 上传。

如果你只是想让朋友今晚就能进服，面板版省掉的是装 Java、装核心、配启动脚本这一整套流程。如果你打算长期运营、要挂插件官网或者同时跑多个服务端，VPS 更合适。

配置本身是弹性的：内存、带宽、硬盘都能在购买页往上调。硬盘扩容的单价有实测文章写成 1 元/G/月，带宽加量的单价在不同机房和机型下不一样，最终以结算页显示的数字为准。

游戏云 VPS 全系配 NVMe 固态，标配 30G 系统盘 + 20G 数据盘和 200M 下行带宽。这几个数对开服的实际意义是：世界存档放在 NVMe 上，区块加载和自动备份都快；下行带宽宽，玩家下载资源包不容易卡。真正限制联机体验的是上行带宽，所以选配置时把注意力放在上行那 10M、15M、20M 上。

价格还有一层变量是机房。同规格机型在不同地区、不同 CPU 型号下报价不一样，第三方评测里出现过 4 核 8G 15M 标价 220 元/月、年付 7 折后折算约 154 元/月的情况。买之前先确定你和玩家主要来自哪个运营商，再挑机房，别只看数字。

## NAT 共享 IP 还是加钱上独立 IP

这是新手最容易忽略的一步，也是买完才后悔的常见原因。

游戏云支持两种公网 IP 模式：

- **NAT 模式（默认）**：和别人共用一个公网 IP，可以配置 15 条端口转发。开 MC 服完全够用，但玩家连接时要填「IP:端口」，端口不是默认的 25565 就要在地址后面带上：比如 `xxx.xxx.xxx.xxx:25565`。
- **独立 IP**：单独占用一个公网 IP，端口全开，防御也独享。适合同时跑多个服务、需要固定地址、或者不想让玩家记端口的场景。

独立 IP 可以购买后随时增购或删除，价格随机房和防御规格变化，以购买页为准。官网也提了一句：大陆机房的网站或常用端口 HTTP 业务需要先备案并过白才能用域名访问——纯 MC 联机不受这条影响，但如果你打算顺便搭个插件服官网，得先把这事算进去。

只有几个朋友玩的话，NAT 模式能省下一笔钱；要长期运营、玩家上百，独立 IP 值这个价。

## 固定计费和动态计费，哪个更划算

游戏云提供两种计费模式：

- **固定计费**：按月固定价格，用满不用满一个价。适合 7×24 小时长期开着的服。
- **动态计费**：基础月租或日租更低，再根据 CPU 实际超额使用率按天结算。短时间内高频吃 CPU 的服，或者只想周末开服的场景，这种模式更省。

面板版对间歇性开服更友好，官方论坛的产品介绍里提到过按天计费、当天不开机不收费、数据保留 30 天的机制。这类规则会调整，下单当天在购买页确认一次最稳妥。

## 优惠、试用和退款规则

雨云这块的规则比较明确，但有几个限制必须提前知道，不然退款时会很被动。

**新用户首月 5 折券**：通过优惠链接注册并绑定微信后自动发放，官方产品页上直接写着"新用户可领首月 5 折券"。这是用来试用服务的最低成本方式。

**1 元试用 1 天**：云服务器和游戏云产品可以 1 元试用一天，每款限 1 次，每周同地域可试用 1 次。试用产品到期后 12 小时内不续费会自动回收，且不在 7 天无理由退订范围内。

**长期付费折扣**：年付 7 折是多个来源一致提到的固定政策，可与优惠券叠加。以 220 元/月的进阶级为例，年付 7 折后折算约 154 元/月。季付、半年付也有相应折扣档位，具体力度以结算页为准。

**7 天无理由退订**：支持退款至余额，但每个账号限 3 次，且**领取过消费积分的产品不再支持退订**——领取时会有弹窗提示。日付等非月付产品不支持退订。

**积分体系**：每日签到可得 500 积分，消费返积分约 10%～20%，2000 积分折 1 元，积分可以兑换优惠券、续期服务器或提现。积分商城里还能兑换免费的低配游戏云（入门 E5 型号），需要靠积分续期维持。这条路适合预算极紧、练手性质的服。

## 三档预算的具体建议

**只有 3～8 个朋友玩，版本不高**：入门级 2 核 4G 够。低版本纯净服单核压力小，必要时把视距往下调一格，比加钱换 CPU 见效快。配上传的首月 5 折券，第一个月的成本很低。

**10～25 人，带插件或者轻度模组**：直接上进阶级 4 核 8G。内存留余量比堆带宽重要——模组包对内存的胃口远大于插件服，2G 内存跑 50 个 mod 很快就会 OOM。

**30 人以上，或者 200 mod 级别的整合包**：超高端 6 核 12G 起步，同时优先挑高主频机型。这个阶段别在 CPU 上省，掉帧和 TPS 波动会直接赶走玩家。

有一条通用原则：不要为了"以后可能有人来玩"一次性买太高。MC 的卡顿大多出现在单核吃满和内存不足，盲目加带宽解决不了这两个问题。

## 买完之后怎么开服

流程本身不复杂，官方和玩家社区都有教程，大致是这几步：

1. 确认机房和计费模式，下单。需要保留长期存档的，别选日付。
2. 进入游戏云管理页，选择"重装/切换游戏"，装载对应环境。面板版直接选 Java 版本；VPS 版可以自己装 MCSM 或翼龙面板。
3. 上传服务端核心，修改启动脚本里的 jar 文件名，然后保存。
4. 启动前把 `eula.txt` 里的 `false` 改成 `true`，这一步不做，服务器会直接退出。
5. 处理器款设置和端口转发规则：NAT 模式下你要把内部端口映射到公网端口，然后把「IP:端口」发给玩家。

第一次开服失败，九成是上面第 4 步或者第 5 步。文件上传走 SFTP，建议用带 SFTP 支持的客户端，注意把编码设为 UTF-8，否则启动脚本里的中文会变乱码。

## 几个常见问题

**2 核 4G 能带多少人？**
按官方参考，纯净服 12 人以上、mod 服 6 人、200+ mod 整合包只有 1 人。别只记住人数那一栏，你的服务端类型才是决定因素。

**玩家连不上，提示连接超时怎么办？**
先确认服务端已经正常启动，再检查 NAT 端口映射是否配置正确。NAT 模式下玩家必须带端口号连接，这是最常见的失败原因。

**可以随时升级配置吗？**
可以。游戏云支持随时升级、降级和弹性变配，面板版还支持切换 CPU 机型，不用为了可能的增长一次性买高配。

**不想用了怎么退？**
7 天内可自助退订退款至余额，每账号 3 次机会。注意别在退订前领取产品消费积分，领了就失去退订资格。

挑服务器的核心其实就是一句话：先确定你要开什么服、多少人玩，再拿这两个条件去对配置，剩下的价格、优惠和 IP 模式都是在这之后才需要考虑的事。
